## 🚀 Instalación y Desarrollo

### Prerrequisitos
- Node.js 18+
- pnpm (recomendado) o npm

### Comandos de Desarrollo
```bash
# Instalar dependencias
pnpm install

# Servidor de desarrollo
pnpm run dev

# Construir para producción
pnpm run build

# Vista previa de producción
pnpm run preview
```
